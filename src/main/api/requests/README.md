# Старый стиль — оставлено для сравнения

Реквестеры из этой папки в тестах **не используются**. Актуальный код живёт
в `src/main/api/foundation/` (`CrudRequester`, `ValidateCrudRequester`,
`ErrorCrudRequester`) и вызывается через слой шагов `src/main/api/steps/`.

Папка оставлена намеренно: здесь каждый эндпоинт — отдельный класс со своим
запросом. Хорошо видно, что дало разделение на слои — общий транспорт,
спеки запроса и ответа, разбор по модели и шаги Allure собраны в одном месте,
а не продублированы восемь раз.

Удалять при уборке проекта не нужно.
